Maple Dental: a holiday turned into a working day

You're checking that when an admin marks a holiday as a working day, plans use it, and go back when it's undone.

Do

  1. New estimate: title S7 Maple Dental, client Maple Dental.
  2. Scope & risk → Start guided scoping. Section 2: 6 pages, 2 templates, everything else No. Untick sections 4, 5, 6 and 8.
  3. Section 7: Project Start Date 2027-01-11, review turnaround 1.
  4. Generate line items → Adjust → Best-fit. Open Scope & risk and read the launch date in the summary at the top (A).
  5. Settings → Workspace → Holidays: set Martin Luther King Jr. Day to Working.
  6. Go back to the estimate. Read the same launch date (B).
  7. Back in Holidays, set MLK Day to Day off again. Check the estimate: read the launch date (C).
  8. Approve → Start project → Review schedule → Confirm & create.

Check

  • "Visual design system" runs Jan 14–19, stepping over Jan 18. In Review schedule, no task is dated Jan 18.
  • The Who does the work card shows the same launch date as the summary.
